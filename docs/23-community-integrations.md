# Community Integrations

Third-party integrations and adapters built by the community on top of the RelayWapp WhatsApp Gateway REST API.

> **Looking for Chatwoot, Typebot, and other first-party integrations?** Those ship as official
> sandboxed plugins on the Integration Fabric and are installed through the gateway's remote plugin catalog.
> This page lists only community-built projects.

> ⚠️ **These projects are community-maintained and are not affiliated with or endorsed by RelayWapp WhatsApp Gateway.**
> They may lag behind RelayWapp WhatsApp Gateway API changes. Verify compatibility and review the source before using
> them in production.

| Integration         | Platform                                                      | Source                                                                                                                                         | Notes                                                                                                                                  |
| ------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **ioBroker.openwa** | [ioBroker](https://www.iobroker.net/) (home / IoT automation) | [ThorstenBoettler/ioBroker.openwa](https://github.com/ThorstenBoettler/ioBroker.openwa) · [npm](https://www.npmjs.com/package/iobroker.openwa) | Send text / image / video / audio / document messages to chats and groups through the RelayWapp WhatsApp Gateway REST API, with Blockly blocks. Early stage. |

Maintain an integration built on RelayWapp WhatsApp Gateway and want it listed here? Open a PR adding a row (or an issue), including the repository link and a one-line description.
